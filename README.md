# eclipse-unity-visual-novel
# Текстовая визуальная новелла на Ink

## Описание

Проект реализует текстовую визуальную новеллу с интеграцией движка **Ink**. Управление сюжетом, диалогами и ветвлением осуществляется через Ink-файлы, а логика сохранений, отображения статов и навигации по меню написана на C#.

## Структура скриптов (Assets/Scripts/)

### Core – Базовые компоненты системы

| Скрипт | Назначение |
|--------|-------------|
| `OverlayManager` | Управление поведением UI-панелей (включение/выключение). Привязывается к конкретному диммеру для работы на разных сценах. |
| `SeriesManager` | Хранение серий и их привязка к соответствующим Ink-файлам. |
| `Singleton` | Базовый Singleton для глобальных менеджеров. |

### Data – Данные и статы

| Скрипт | Назначение |
|--------|-------------|
| `StatDefinition` | Определение статов: внутреннее имя (для Ink), отображаемое имя, иконка. |
| `StatsDatabase` | Работа с базой данных статов (загрузка, доступ, обновление). |
| `TransformExtensions` | Вспомогательные методы для очистки дочерних элементов ScrollBar (перед обновлением информации). |

### Ingame – Игровая сцена (GameScene)

| Скрипт | Назначение |
|--------|-------------|
| `InkDialogueManager` | Основной мост между Ink и игровой сценой. Обрабатывает диалоги, выборы, переходы по меткам. |

### Menu – Меню (MenuScene)

| Скрипт | Назначение |
|--------|-------------|
| `MenuManager` | Главный менеджер меню. Аналог `InkDialogueManager` для сцены меню. |
| `SlotMenuManager` | Управление переключением слотов сохранений. |
| `StatsScreenManager` | Отображение панели статов в меню. |

### SaveSystem – Система сохранений

| Скрипт | Назначение |
|--------|-------------|
| `SaveSystem` | Полный цикл работы с сохранениями: пути к файлам, список переменных для сохранения, переключение между слотами, загрузка/запись. |

### UI – Пользовательский интерфейс

| Скрипт | Назначение |
|--------|-------------|
| `CursorManager` | Установка кастомного курсора. |
| `SlotItem` | Отображение элемента (ячейки) в экране выбора слотов сохранений. |

## Важные папки и ресурсы

| Путь | Содержимое |
|------|-------------|
| `Assets/Prefabs/` | Префабы кнопок, уведомлений, иных UI-элементов. |
| `Assets/TextMesh Pro/` | Шрифты с бесплатными лицензиями (TextMesh Pro). |
| `Assets/Series/` | Ink-файлы серий (`.ink` или скомпилированные `.json`). |
| `Assets/Resources/Images/` | Графика для UI (фоны, кнопки, панели). |
| `Assets/Resources/Sprites/` | Временные спрайты персонажей (для разработки/прототипирования). |
